SLIMANE — PERSONAL PORTFOLIO

A responsive English-language portfolio website built with HTML, CSS, and a small amount of JavaScript.

RUN LOCALLY
1. Extract the ZIP folder.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.

BEFORE PUBLISHING
- Add your real email address to the contact link in index.html.
- Add GitHub / LinkedIn links if you want them displayed.
- Check that the name spelling SLIMANE is how you want it shown.
